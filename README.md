# IPL_ball-by-ball-data-analysis
Exploratory Data Analysis of IPL ball-by-ball data using Python, Pandas, NumPy, Matplotlib and Seaborn.
# 🏏 IPL Ball-by-Ball Exploratory Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on IPL ball-by-ball delivery data using Python.

The analysis explores batting, bowling, team performance, runs, wickets, boundaries, dismissals, extras, over-wise scoring patterns, and fielding performance.

## 🎯 Objectives

* Analyze top run-scoring batsmen
* Identify leading wicket-taking bowlers
* Compare total runs scored by teams
* Analyze runs scored per delivery
* Study fours and sixes
* Analyze dismissal patterns
* Examine over-wise scoring trends
* Analyze extra runs
* Study numerical correlations
* Analyze fielding performance
* Identify and handle missing values and duplicate records
* Perform basic outlier analysis

## 🛠️ Technologies & Libraries

* Pandas

### 📈 Scoring Analysis

## 🧹 Data Preprocessing

The dataset was cleaned before analysis by:

* Handling missing values in dismissal-related columns
* Removing duplicate records
* Checking data types
